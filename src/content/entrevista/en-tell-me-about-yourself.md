Keep it to **60–90 seconds** and use a **present → past → future** structure:

"I'm a backend developer focused on **Java and Spring Boot**. **Currently**, I'm building a payments service as my portfolio project: a REST API with PostgreSQL, Flyway migrations, integration tests with Testcontainers, and events published to Kafka using the outbox pattern.

**Before that**, I worked for three years in customer support at a fintech, which is where I got interested in how the systems behind it work. I studied in a structured way, and one project I'm proud of is an LRU cache with O(1) operations that I implemented from scratch and benchmarked.

**Now** I'm looking for a role where I can work on distributed backend systems with a team that values testing and code review — which is why this position caught my attention."

Practice out loud until it sounds natural, not memorized.
