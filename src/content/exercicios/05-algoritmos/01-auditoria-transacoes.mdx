## Contexto

O time antifraude de uma adquirente de cartões recebe contestações do tipo "fui cobrado R$ 15,00 e não reconheço". Muitas vezes a cobrança é a **soma de duas transações** legítimas. Os analistas também procuram **transações duplicadas** enviadas em sequência e **clientes que compraram uma única vez** (perfil comum de teste de cartão roubado). Os arquivos têm milhões de linhas, e o script atual, com laços aninhados, leva horas.

## Requisitos

| Método | Retorna |
|---|---|
| `parQueSoma(valoresEmCentavos, alvo)` | `[i, j]` com `i < j`, o par com o **menor j** possível; array vazio se não houver |
| `duplicataEmJanela(ids, k)` | `true` se o mesmo id aparece duas vezes a no máximo `k` posições |
| `primeiroClienteUnico(clientes)` | `Optional` com o primeiro cliente (na ordem de chegada) que aparece **uma única vez** |
| `maiorSequenciaDeDias(dias)` | Tamanho da maior sequência de inteiros consecutivos presentes, em qualquer ordem |

## Exemplos

```text
parQueSoma([1500, 700, 300, 1200], 1500)   → [2, 3]     (300 + 1200)
duplicataEmJanela([t1, t2, t3, t1, t4], 3) → true       (distância 3)
primeiroClienteUnico([ana, bia, ana, caio, bia]) → caio
maiorSequenciaDeDias([100, 4, 200, 1, 3, 2])     → 4    (1, 2, 3, 4)
```

## Requisito não funcional

**Todos em O(n).** O teste `desempenho` roda com 1 milhão de itens e exige menos de 2 segundos. Força bruta (O(n²)) não passa, e ordenar para `maiorSequenciaDeDias` (O(n log n)) é aceitável, mas a solução-alvo é O(n).

- `trincaQueSoma(valores, alvo)` (3Sum) em O(n²).
- `todosOsPares(valores, alvo)`: todos os pares distintos de **valores**, sem repetir.

### Complexidades

| Método | Tempo | Memória |
|---|---|---|
| `parQueSoma` | O(n) | O(n) |
| `duplicataEmJanela` | O(n) | O(n) (ou O(k) com uma janela de `HashSet`) |

| `maiorSequenciaDeDias` | O(n) amortizado | O(n) |

### Detalhes que fazem diferença

- **`putIfAbsent` no Two Sum**: guarda o **primeiro** índice de cada valor, o que garante o par com o menor `i` para aquele `j`.
- **`Map.put` devolve o valor anterior**: em `duplicataEmJanela`, uma única operação atualiza a posição e informa onde o id estava.
- **`long` para centavos**: somas de valores monetários grandes estouram `int`.
- **Análise amortizada**: em `maiorSequenciaDeDias`, o `while` só roda a partir do início de cada sequência, então cada número é visitado no máximo duas vezes no total.
