## Contexto

Quatro demandas pequenas chegaram ao time de plataforma, e todas têm a mesma estrutura por trás:

1. um **pré-validador** que rejeita payloads com `()`, `[]` e `{}` desbalanceados antes de enviá-los ao parser (economiza CPU sob ataques de payload malformado);
2. para o app de agro, "**quantos dias até uma temperatura maior**" em cada dia da previsão;
3. uma **calculadora de regras** que recebe fórmulas em notação polonesa reversa, vindas de uma ferramenta legada;
4. a **normalização de caminhos** de um gateway de API, para que `/api//v1/./pedidos/../pedidos` e `/api/v1/pedidos` caiam na mesma regra.

## Requisitos

| Método | Comportamento |
|---|---|
| `balanceada(expressao)` | `( ) [ ] { }` corretamente aninhados; outros caracteres são ignorados |
| `diasAteTemperaturaMaior(temperaturas)` | Para cada dia, a distância até um dia estritamente mais quente (0 se nunca); **O(n)** |
| `avaliarRpn(expressao)` | Tokens separados por espaço, `+ - * /` (divisão inteira); expressão malformada → `IllegalArgumentException` |
| `simplificarCaminho(caminho)` | Caminho absoluto canônico: trata `.`, `..` e barras repetidas |

## Exemplos

```text
balanceada("{\"itens\": [1, 2, {\"x\": (3)}]}")   → true
balanceada("([)]")                                 → false
diasAteTemperaturaMaior([73,74,75,71,69,72,76,73]) → [1,1,4,2,1,1,0,0]
avaliarRpn("3 4 + 2 *")                           → 14
simplificarCaminho("/a/./b/../../c/")             → /c
simplificarCaminho("/../")                         → /
```

### Pontos-chave

- **`Map.of(')', '(', …)`** evita um `switch` para descobrir o par de cada fechamento, e `equals` compara os `Character` corretamente.
- **Pilha monotônica guarda índices**, não temperaturas: é o índice que permite calcular a distância.
- **Switch com setas aninhado** em `avaliarRpn`: o externo classifica o token, o interno escolhe a operação. `case "", "." -> { }` em `simplificarCaminho` mostra que um `case` pode, legitimamente, não fazer nada.
- **`pollLast()`** em `simplificarCaminho` devolve `null` com a lista vazia em vez de lançar exceção — exatamente o comportamento desejado para `..` na raiz.
